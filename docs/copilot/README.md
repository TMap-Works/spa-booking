# Copilot IA

Un chat intégré au produit, branché sur Claude, qui répond aux questions de
l'utilisateur sur le salon et le site, lui propose les actions utiles selon sa
session, et agit dans l'interface à sa place. La réservation et les rendez-vous
passent en premier, parce que ce sont eux qui font entrer le chiffre d'affaires.

**Hors du périmètre MVP** (CDC §1.4) : le chantier est ouvert par
l'[ADR 0018](../adr/0018-copilot-ia-dans-le-produit.md), à côté du MVP et sans
rien retirer à ses garanties.

| Document | Ce qu'il dit |
|---|---|
| [specification.md](specification.md) | Ce que le copilot fait, pour qui, avec quelles garanties, et à quoi on reconnaît qu'il est fini |
| [inventaire.md](inventaire.md) | Chaque écran, par rôle : ce qu'on y fait, et ce que le copilot y fait |
| [plan-implementation.md](plan-implementation.md) | Les phases, les tickets, leurs empreintes de fichiers et l'ordre de livraison |

Ordre de lecture : l'ADR pour le *pourquoi*, la spécification pour le *quoi*,
l'inventaire pour le *où*, le plan pour le *quand*.
